Configuration et sécurité

Le backend lit la clé OTCharts depuis le fichier .env (jamais depuis le navigateur). Cette API tierce est indépendante et non affiliée à Pocket Option ; elle fournit des cours en lecture seule et ne passe pas d'ordres. Le compte Pocket Option n'est ni connecté ni modifié.

Ne colle jamais ici ton mot de passe Pocket Option, ton code 2FA ou ton SSID. La connexion de données ne donne pas accès à ton solde ni à tes trades.
